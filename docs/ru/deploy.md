# Инструкция по деплою overnet-релеев

Для запуска MVP сети вам нужно запустить 3 релея на ваших серверах за границей.

## 1. Сборка (Для Linux серверов)

Поскольку вы находитесь на Windows, проще всего собрать `overnet-cli` прямо на Linux серверах, либо с помощью `cross`:
```bash
cargo build --release -p overnet-cli
```
Готовый бинарник будет лежать в `target/release/overnet-cli`. Скопируйте его на все 3 сервера.

## 2. Ключи и адреса
Каждый релей при старте генерирует себе ключ (onion pubkey) случайным образом, либо вы можете модифицировать код, чтобы он читал ключ из файла (для постоянного onion адреса). В MVP мы позволим узлам генерировать новый ключ при старте и выводить его на экран.

## 3. Запуск серверов (Топология A -> R1 -> R2 -> Service)

Мы настроим 3 сервера.

**Сервер 1 (Service / Конечный узел):**
Запустите на 1-ом сервере (IP: `SERVER_1_IP`):
```bash
./overnet-cli service 0.0.0.0:4040
```
> Скопируйте его `onion pubkey`.

**Сервер 2 (Релей 2):**
Запустите на 2-ом сервере (IP: `SERVER_2_IP`):
```bash
./overnet-cli relay 0.0.0.0:4040 <PUBKEY_СЕРВЕРА_1>@SERVER_1_IP:4040
```
> Скопируйте его `onion pubkey`. (Этот релей будет перенаправлять пакеты к Серверу 1).

**Сервер 3 (Релей 1):**
Запустите на 3-ем сервере (IP: `SERVER_3_IP`):
```bash
./overnet-cli relay 0.0.0.0:4040 <PUBKEY_СЕРВЕРА_2>@SERVER_2_IP:4040
```
> Скопируйте его `onion pubkey`. (Этот релей будет перенаправлять пакеты к Серверу 2).

## 4. Клиент на вашем ПК (РФ)
Теперь у вас есть путь `Релей 1 -> Релей 2 -> Сервис`. Вы знаете их `pubkey`.

Клиент v0.1 (Tauri-приложение, позже удалённое из репозитория) принимал этот
путь маршрутизации с `pubkey` всех трёх узлов.
(Для полноценной работы из UI Tauri нам нужно добавить эти pubkey в конфигурацию клиента).
